操作教程

三分钟上手，不用翻文档

① 换下载路径

「下载」页 → 保存位置右边的「更改目录」→ 选一个盘（比如 D:\小抄）。

网盘下载会在这个目录下再建一层 夸克网盘\，里面的层级和网盘里完全一样，你在网盘里怎么分类，本地就怎么分类。

② 右键换绑悬浮球

右键桌面上的球 → 展开「换绑到」→ 点一个分类（比如把「龙宫」改成「虫谷」）。

当前绑的那个会打勾。换完立刻生效，球上的封面也会跟着变。

③ 快捷键显隐

热键 A（默认 Alt+X）：小抄大图 显 / 隐。按一下弹出来，再按一下收回去。

热键 B（默认 Alt+Z）：只控制悬浮球。全屏打游戏时按一下，屏幕上立刻干干净净。

键位可以在上面的「快捷键」卡片里改：点一下按键栏，按下新组合键即可。被别的软件占用时会标红，换一个就好。

④ 调透明度和大小

小抄窗口上：Alt + 滚轮 调透明度，Ctrl + 滚轮 调窗口大小。

也可以拖上面的两个滑杆，效果一样。

⑤ 翻页 & 临时穿透

大图打开后，滚轮或 ← → 翻上/下一张，Esc 关闭。

鼠标离开窗口约 2.6 秒会自动回到「穿透」状态，不会挡住游戏点击；把鼠标移回窗口上会立刻恢复可操作。

想一直锁死穿透，就打开「锁定穿透」开关。

⑥ 整目录下载（龙宫 / 虫谷这种）

「网盘」页左侧目录树里，每个文件夹名字左边有一个小方框 —— 点它就是「整个文件夹一起下」，不用一个个勾。

也可以进到目录里单独勾几张，再切到别的目录接着勾，底部会统计「已选 N 个文件 + M 个整文件夹」。

点「开始下载」会先预检：要下几个、跳过几个、共多少 MB，确认了才真下。

!
游戏要设成「无边框窗口」或「窗口化」

独占全屏会把所有叠加层挡在下面 —— 这是系统层面的限制，任何准星 / 悬浮窗工具都一样。

如果游戏是「以管理员身份运行」的，本程序也要右键 → 以管理员身份运行，否则 Windows 不允许低权限窗口盖在它上面。
