# 云小抄 · PC

Windows 桌面版。把 Android 上「云小抄」那套悬浮攻略、准星、碎格 / 浮现动画、自定义开屏搬到了电脑上，外加**多悬浮球**与一套**网盘文件管理与下载**（目录 1:1 复刻、整文件夹下载、已下载绝不重复下）。

> 基于 [云析 YunX](https://github.com/CYQawa/YunX)（CYQawa）与 Android 版云小抄二次开发，AGPL-3.0。
> 视频解析和大文件转存用官方 [云析 PC 端](https://github.com/tidain/YunX-Desktop)，主界面「云析 PC」页有一键下载。

---

## 直接运行

1. 解压 `云小抄-PC-v1.4.0-win64.zip`（整个文件夹一起解压，别只拖 exe 出来）。
2. 双击 `YunX Guide PC.exe`。
3. 第一次打开会提示选攻略文件夹 —— 把手机上的「本地小抄」目录整个拷过来就行，里面一个子文件夹一个分类。

没有现成的本地文件夹？用下面的「网盘一键下载」直接从分享链接拉一份下来，或者进「网盘」页从自己的网盘挑。

未签名的小程序，Windows 可能弹 SmartScreen：**更多信息 → 仍要运行**。

系统要求：Windows 10 / 11 64 位。不需要装 Java、Node 或运行库。

## 三个窗口

| 窗口 | 是什么 | 怎么控制 |
|---|---|---|
| 主界面 | 设置、准星预览、下载入口 | 托盘图标 / 双击桌面快捷方式 |
| 小抄悬浮窗 | 透明置顶的攻略窗 | `Alt+Q`，或主界面「开启小抄」 |
| 准星层 | 一张透明置顶的准星图 | `Alt+E` |

关掉主界面不会退出程序 —— 小抄和准星还在跑，托盘图标能叫回来。要彻底退出用托盘菜单的「退出」。

## 游戏模式（始终置顶）

小抄和准星默认就开着「游戏模式」，做了两件事：

1. **呼出不抢焦点**：`Alt+Q` 呼出时用 `showInactive()`，游戏不会因为「小抄弹出来了」就切出去。你主动去点小抄的那一刻才会激活它 —— 想一直只读不打扰，把「锁定穿透」打开。
2. **每 0.8 秒重新压回最上层**：Windows 的置顶只是「进 topmost 组」，组内顺序谁最后动谁在上面。游戏、录屏、输入法、资源管理器弹框都可能把你挤下去。所以主进程定时重新 `setAlwaysOnTop` + `moveTop`。

开关在「小抄 → 窗口 → 游戏模式 · 始终置顶」，关掉就回到普通窗口顺序（适合不玩游戏、只想桌面看攻略）。

> **v1.4.0 把「一个球」升级成了「一套悬浮球」**
>
> 桌面最多放 **3 个球**，每个绑一个分类（龙宫 / 虫谷 / 地图）。点球直接弹出该分类的**第一张图**，不用先进网格再点。**右键球**可以随时换绑到别的分类；拖到哪记到哪，换显示器也不会丢（每次落点都会夹回工作区）。
>
> **双模式显隐**，两个热键互不干扰：
> - `Alt+X`（热键 A）：小抄大图 显 / 隐，任何状态下都生效
> - `Alt+Z`（热键 B）：只控制悬浮球，全屏打游戏时按一下屏幕上干干净净
>
> 窗口默认**智能穿透**：鼠标离开约 2.6 秒自动回到穿透，不挡游戏点击；鼠标挪回窗口立刻恢复可点，不用再按热键。`Alt+滚轮` 调透明度，`Ctrl+滚轮` 调大小，`滚轮` 翻页。
>
> **网盘支持整文件夹下载**：目录树每一行左侧有独立的小方框，点一下就是「整个文件夹一起下」，子目录会递归展开（上限 60 个目录 / 2 万个文件，超了会明确提示而不是静默少下）。勾选只记相对路径，O(1)，不会因为一个文件夹有几千张图就卡住。
>
> 这一版还把三个 Windows 上会出事的地方补上了：
>
> | 问题 | 以前 | 现在 |
> |---|---|---|
> | 异步异常没人接 | Node 20 直接退进程，用户只看到「双击没反应」 | 全局兜底 + 落盘日志（`userData/logs/`），可在关于页导出 |
> | 落盘路径硬拼 | 网盘里出现 `..` 能写到保存目录之外 | 全链路 `resolveInside` 校验，越界直接跳过并记日志 |
> | 目录扫描无上限 | 绑到几万文件的目录时主进程假死 | 最多 3000 条目 / 60ms，超了带部分结果返回 |

> **v1.3.0 把「下载」升级成了「网盘管理」**：侧边栏多一个「网盘」页，左边目录树（从网盘根一层层展开）、中间文件列表、右边下载队列。支持**跨目录勾选**——在「人物立绘/主角色」勾两张，切到「NPC」再勾三张，底部会写「已选 5 个 · 来自 2 个目录」，一起下。本地目录跟网盘**1:1 复刻**（`保存目录/夸克网盘/人物立绘/主角色/xxx.png`）。
>
> **重复下载这次是从根上堵死的**，判定依据不是文件名、也不是网盘 fileId，而是**相对路径**：
>
> | 条件 | 说明 |
> |---|---|
> | 本地相对路径存在且是文件 | 以「从下载根算起的相对路径」为唯一身份，网盘里挪了位置就是新文件 |
> | 大小一致 | 网盘没给大小时跳过这条，但不能当"已下载" |
> | 修改时间一致（容差 2 秒） | 下载完成会把网盘 mtime `utimes` 写回本地，否则下次比对必然不一致 —— 这是绝大多数"重复下载"工具翻车的地方 |
> | 本地索引里有这条记录 | `userData/pan-index.json`，键是 `(网盘+保存目录, 相对路径)`；区分「我下过的」和「你从别处拷来的同名同大小文件」 |
>
> 四条全过才跳过；网盘侧改了（大小或时间变了）会重下覆盖，本地被改过也会重下。点「开始下载」前会先**预检**，弹窗直接告诉你「要下 3 个 / 已存在跳过 2 个 / 共 2.0 MB」，一个字节都不会白下。实测：同一批 5 个文件下完再点一次，预检是 `0 个要下载`，一次直链请求都不会发。
>
> 队列是**任务串行、任务内 3 条车道**（不是所有任务一起并发，那样必被网盘风控），每个任务能暂停 / 继续 / 取消 / 重试失败项，实时显示速度与剩余时间。

> **v1.2.6 把「挑文件」做轻了，也把小抄窗的卡顿治了**：分享弹窗多一个「全部下载」直接整份拿；选择界面改成分类默认折叠、每行写着「30 项 · 26 MB」、右侧一个「下这个」一键只下这个分类，另有「展开全部」；勾选统计从「每个目录重数自己子树」（1800 个文件约 200 万次循环）改成自底向上一次遍历。缩略图从同步生成改为主进程异步队列（20 张 1648ms → 671ms，事件循环最长冻结 1653ms → 39ms），卡片加了 `content-visibility` 跳过视口外绘制。
>
> **v1.2.5 加了选择性下载**：粘贴分享链接后不再直接整份拖下来，先解析成文件树（分类 → 子目录 → 文件，带大小），在独立界面里勾选，只下选中的。支持全选 / 全不选 / 只选图片、目录级半选、单独改保存位置。解析结果缓存 30 分钟，期间可以直接开始下载。
>
> **v1.2.4 加了显示模式检测**：主界面「小抄 → 窗口」多了一行状态，用 Windows 自带的 `SHQueryUserNotificationState`（系统只读查询，不注入、不挂钩游戏）判断当前前台是不是独占全屏。独占全屏时标红并给出结论：叠加层收不到鼠标，改「无边框窗口」才能点。这一行和 v1.2.3 的遮罩修复是两件事：前者是系统显示模式的硬限制，后者是本程序自己的缺陷。
>
> **v1.2.3 修了真正让「所有按钮都点不了」的 bug**：网盘弹窗（`#cloudModal`）和分享弹窗（`#shareModal`）是常驻 DOM 的全屏遮罩，之前只把 `opacity` 归零，`pointer-events` 仍然是 `auto`、`z-index` 还是 9500 —— 等于一张看不见的玻璃铺在整个界面上，所有点击都被它吃掉。所以 v1.2.0 / v1.2.1 改 `focusable` 不会有任何效果：问题从头到尾就不在窗口层。现在遮罩默认 `visibility: hidden; pointer-events: none`，只有真正弹出时才接收点击。
>
> v1.2.1 修的是另一个独立问题：v1.2.0 为了「不抢焦点」把窗口设成 `focusable: false`，这在 Windows 上等于 `WS_EX_NOACTIVATE`，鼠标消息送不到页面。现在固定 `focusable: true`，改用 `showInactive()` 控制焦点。
>
> 小抄窗里那个 ⛓ 按钮也改了：点一下不再立刻穿透，而是 3 秒倒计时，期间再点一次可撤销；锁定生效后按钮会亮起，避免「误触之后整窗点不动又不知道为什么」。
>
> 万一以后又遇到「点不动」：按 **`Alt + Shift + R`**，或右键托盘图标 →「小抄点不动？重置悬浮窗」。主界面「窗口」卡片里也有一行实时状态，会直接写「可正常点击」还是「锁定穿透中」。

**还是被盖住的话，按顺序排查：**

| 现象 | 原因 | 处理 |
|---|---|---|
| 小抄能看见但完全点不动，或根本看不见 | 游戏是「独占全屏（D3D 独占）」 | 改成「无边框窗口 / 窗口化全屏」。独占全屏下 Windows 会停掉桌面合成，叠加层既画不上去、也收不到鼠标消息 —— 这是系统限制，调窗口参数没有用。主界面「小抄 → 窗口」现在有一行实时检测，会直接标出当前是不是独占全屏 |
| 窗口化也看不到，或一闪就没了 | 游戏以管理员权限运行 | 本程序也右键 →「以管理员身份运行」。Windows 不允许低权限窗口盖在高权限窗口上面（UIPI 限制） |
| 偶尔被挤下去，0.8 秒内又回来 | 别的置顶窗口抢了顺序 | 正常，看门狗会抢回来。觉得闪就把那个软件也关掉 |
| 小抄挡住主界面 | 置顶的必然结果 | `Alt+Q` 收起，或把主界面挪开 |

## 地图覆盖模式（v1.5.0）

玩家开游戏地图时，把小抄贴在地图上边看边对照。开关三处都有：悬浮窗标题栏 `◎`、设置页「小抄 → 窗口 → 地图覆盖模式」、全局热键 `Alt+M`。

打开后会发生三件事：

1. **透明度自动降到 62%**：小抄看得清，下面的地图也看得清（你之前手动调得更低就不覆盖）
2. **保持可点 / 可穿**：鼠标挪到小抄上就能翻页、拖动；离开约 2.6 秒自动穿透，点击直接落到游戏
3. **锚点缩放**：`Alt+Shift+滚轮` 等比缩放小抄（60%–160%），缩放围绕锚点进行；`Alt+Shift+左键` 把锚点设在鼠标处

缩放比例、锚点、窗口位置都会存进 `config.json`，下次打开还原。

> **为什么是手动缩放，不是自动跟随？**
> Electron 读不到游戏内部的缩放比例。这一版先做「手动标定」：先把小抄摆到地图对应位置，再用 `Alt+Shift+滚轮` 跟着地图缩放对齐。玩家实测手感 OK 之后，再评估要不要上截屏识别自动跟随（更重，且独占全屏下不可用）。

### 测试地图（v1.6.0）

没有 PC 版游戏也能自测：设置页「小抄 → 窗口 → 测试地图 → 打开」，会开一张模拟地图窗口。

- **滚轮**缩放地图，**按住拖动**平移，**点击**任意位置计数 +1
- 把小抄盖上去，鼠标移开约 2.6 秒再点地图：**计数 +1 就说明穿透成功**
- 地图左上角有缩放百分比，可用来对比 `Alt+Shift+滚轮` 的小抄缩放

测试地图是纯本地页面，不注入、不读取任何游戏进程。

## 网盘小抄一键下载

小抄页的「网盘一键下载」有两个入口：

**从分享链接下载** —— 把夸克 / UC 的分享链接或整段分享文案粘进去（带提取码也行），整份小抄连目录结构一起下到：

```
文档\云小抄\<分享标题>\
```

**从我的网盘下载** —— 点「打开登录页」，在弹出的官方网页里扫码 / 账密登录（本地不存任何账号密码，只留 Cookie）。登录成功后进到放小抄的文件夹，点「下载这个目录」：

```
文档\云小抄\<选中的文件夹名>\
```

登录这块（v1.2.2 重做）：

- **二维码就在登录窗右侧**。夸克和 UC 的网页版都把扫码卡片钉在页面右边缘（UC 那张一直贴到 1060px），所以登录窗开到 **1120 宽**，屏幕不够就按比例缩放页面，保证 CSS 视口不低于 1100。之前只有 560 宽，二维码整块在视口外面，看着就像「这页面没有登录入口」。
- **夸克带 `?fr=pc&platform=pc`**。不带这个参数打开的是推广落地页，带上才是 PC 网页版形态，右侧登录卡片才出来。
- **登录成功后自动关闭**，不用手动关窗，主界面会立刻刷新成已登录。
- **打不开就用「粘贴 Cookie」**。在浏览器登录同一网盘，F12 → Application → Cookies → 选 `pan.quark.cn` / `drive.uc.cn`，把含 `__pus` 和 `__puus` 的整段 Cookie 复制进来。粘贴时会自动整理换行和 `Cookie:` 前缀，保存前会真打一次网盘接口验证，过期或复制不全都会当场告诉你。

> 为什么不用账号密码？夸克 / UC 的账密登录有验证码和风控，任何第三方客户端都不该碰你的密码。只留 Cookie，随时能在主界面「退出登录」清掉。

两种方式都是：

- **并发 3 路**，保留网盘子目录结构，文件名自动去掉 Windows 不允许的字符。
- **断点式增量**：已经下过、大小一致的文件直接跳过。作者更新后再点一次，只补新图。
- 下完会显示保存路径，点「设为本地小抄」直接切换过去，按 `Alt+Q` 就能看。
- 保存位置随时能改（「换一个位置」/「打开下载目录」）。

限制：夸克游客链路单文件约 50MB（攻略图远远够用），需要更大的文件请先登录。只支持夸克与 UC；迅雷、百度、123 这些请用云析 PC 端转存。

## 小抄怎么用

- 顶栏拖动窗口，右下角拖大小；底部两条滑杆调透明度和宽度。
- 点文件夹进去，点图看大图。大图里滚轮缩放、拖动平移、双击放大、`←` `→` 翻页、`Esc` 关闭。
- 顶栏的链子图标 = **锁定穿透**：锁上后鼠标直接穿过小抄落到游戏里，不会误点。
  锁上后点不到按钮，按 `Alt+Q` 收起再按一次就自动解锁（收起即解锁）。
- 减号把窗口缩成小球，拖到角落不挡视线，点一下展开。

## 准星怎么用

1. 「准星 → 导入图片」，随便找张 png / jpg。
2. 在预览图上点一下 —— **点哪儿，哪儿就是瞄准点**，图上会画红十字。
3. 调显示宽度和不透明度；纯色图建议留着「画十字线」。
4. 「调整位置」会临时取消穿透，直接把准星拖到屏幕上的位置，再点一次收工。
5. 换枪 / 换游戏就「新建」一套，最多 24 套，`Alt+R` 轮换。

> 准星是**屏幕叠加**，不读游戏内存、不改游戏文件。但部分竞技游戏会把任何叠加层当作违规，用不用自己判断。

**游戏要设成「无边框窗口」或「窗口化」。** 独占全屏会把所有叠加层挡在下面，这是 Windows 的合成机制，任何准星 / 悬浮窗工具都一样。

## 动画

「外观」页把两处动画分开设：

- **入场**（点开程序那一下）：碎格 / 浮现
- **切页**（页签之间）：碎块 / 浮现

碎格是 22px 的小格子铺满屏，按对角线从左上往右下逐块缩掉；浮现是模块一个个从下方浮起、淡入。速度四档，也能整个关掉。

## 开屏

「外观 → 开屏动画」可以换图片或视频（mp4 / webm / mov）。图片停留 1 / 1.8 / 3 秒，视频最长播 15 秒、静音，点一下就跳过。不设就是内置的图标开屏。

上限：图片 20MB、视频 80MB。导入时会复制一份到配置目录，原文件删了也不影响。

## 数据在哪

`%APPDATA%\YunX Guide PC\`

```
config.json     所有设置（含网盘登录 Cookie）
crosshair\      导入的准星图
splash\         开屏图 / 视频
thumbs\         缩略图缓存（可随时删，删了会重建）
```

换电脑把这一个文件夹拷走就行。缩略图缓存按「最近 5000 张 / 512MB」自动清理，不会无限涨。

## 为什么第二次打开快很多

第一次看某个文件夹时，每张图都要从原图解码缩放到 420px 宽；这一步以前只缓存在内存里，关掉程序就没了，所以每次启动都要重来一遍。

现在缩略图会落成 `thumbs\*.jpg`（文件名带原图的修改时间和大小，换图自动失效），第二次打开直接读盘。启动后还会在后台把当前分类的封面和首屏 60 张先预热一遍。

需要 Node 18+。首次 `pack:win` 会下载 Windows 版 Electron（约 110MB），国内可以设：

```bash
set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
```

## 目录

```
src/main/main.js        窗口、协议、全局快捷键、托盘、IPC
src/main/store.js       配置读写
src/main/guide.js       攻略目录扫描 + 缩略图（内存 + 磁盘两级缓存）
src/main/pan.js         夸克 / UC 分享与个人网盘接口
src/main/downloader.js  下载队列：递归列举、并发、增量、取消
src/preload/preload.js  页面与主进程之间的白名单通道
src/renderer/main       主界面（导航、设置、准星预览、开屏、下载）
src/renderer/overlay    小抄悬浮窗
src/renderer/crosshair  准星层
```

页面没有 Node 权限：`contextIsolation` 开着，图片只能通过 `guide://` / `media://` 两条协议读，且限用户选过的目录与文件。

## 和 Android 版的差别

| 功能 | PC |
|---|---|
| 悬浮小抄 | 有。拖动、缩放、透明度、锁定穿透、小球 |
| 攻略来源 | 本地文件夹 + **网盘一键下载**（夸克 / UC 分享与个人网盘） |
| 多套准星 | 有。最多 24 套、点图设锚点、快捷键轮换 |
| 碎格 / 浮现 | 有。入场与切页分开设、四档速度 |
| 自定义开屏 | 有。图片 / 视频 |
| 自动连招 | 没有。要注入按键事件，桌面端风险高、收益低 |
| 视频解析 / 转存 | 不重复实现，入口指向官方云析 PC 端 |

## 常见问题

**小抄 / 准星在游戏里看不见？**
游戏改「无边框窗口」或「窗口化」。独占全屏下叠加层一定看不见。

**锁定穿透后点不到小抄了？**
`Alt+Q` 收起，再按一次就解锁（收起会自动解锁）。

**快捷键没反应？**
大概率被别的软件占了。去「小抄 → 快捷键」换一个，标红就是没注册上。

**下载到一半断了 / 关了程序？**
再点一次同样的链接就行。已经下好的不会重下，只补缺的那几张。

**提示「分享不存在」或「提取码不对」？**
先确认链接在浏览器里能打开、提取码没复制错。夸克分享被作者取消也会报这个。

**下载很慢 / 大量失败？**
换网络或过几分钟再试，夸克对短时间大量请求有频控。登录后下载更稳，也没有 50MB 单文件限制。

**杀毒软件报毒？**
Electron 打包的未签名 exe，常见误报。介意的话按上面的步骤自己构建。

**准星位置有偏移？**
Windows 显示缩放不是 100% 时，拖完位置点一下「一键居中」校准；或者把游戏设成和桌面相同的分辨率。
